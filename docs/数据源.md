# 数据源接入说明

「数据源」模块（`/datasources`，仅 `branch_admin` 可见）用于接入外部数据库 / 搜索引擎 / 向量库，AI 分析引擎（Python `codeact` sidecar）可跨数据源执行查询。

## 支持的数据源一览

共 **15 种**，类型由 `lib/db/schema.ts` 的 `DATA_SOURCE_TYPES` 单一来源维护（DB schema / 前端 / API zod / codeact 分发四处自动同步）。

### 关系型 / SQL（走 SQLAlchemy）

| 类型 | 标识 | 默认端口 | 驱动 | 说明 |
|---|---|---|---|---|
| SQLite（独立文件） | `sqlite` | — | 内置 `sqlite3` | `数据库文件路径` 指向外部 `.db` |
| MySQL | `mysql` | 3306 | pymysql | |
| PostgreSQL | `postgresql` | 5432 | psycopg2 | |
| SQL Server | `sqlserver` | 1433 | pymssql | |
| Oracle | `oracle` | 1521 | **oracledb**（thin 模式） | 需填 `Service Name` |
| DB2 | `db2` | 50000 | **ibm_db** | ⚠️ 需 DB2 clidriver |
| Hive | `hive` | 10000 | pyhive | 认证方式 `NONE / KERBEROS` |
| Impala | `impala` | 21050 | impyla | |

### 搜索引擎

| 类型 | 标识 | 默认端口 | 驱动 | 说明 |
|---|---|---|---|---|
| Elasticsearch | `elasticsearch` | 9200 | elasticsearch-py | 走 ES SQL API，另有 `query_es(index, dsl)` 原生 DSL |

### 向量数据库

| 类型 | 标识 | 默认端口 | 驱动 | 向量检索函数 |
|---|---|---|---|---|
| pgvector（PG 扩展） | `vector_pgvector` | 5432 | pgvector + psycopg2 | `vector_search(table, vec, top_k, metric, output_fields)` |
| Milvus | `vector_milvus` | 19530 | pymilvus | `vector_search(collection, vec, top_k, output_fields)` |
| Qdrant | `vector_qdrant` | 6333 | qdrant-client | `vector_search(collection, vec, top_k, output_fields)` |
| Weaviate | `vector_weaviate` | 8080 / 50051 | weaviate-client v4 | `vector_search(collection, vec, top_k, output_fields)` |
| Chroma | `vector_chroma` | 8000 | chromadb | `vector_search(collection, vec, top_k, output_fields)` |

### 自建协议

| 类型 | 标识 | 说明 |
|---|---|---|
| DTSQL | `dtsql` | 自建 HTTP 服务，需实现 `POST /query`（`{sql, params}` → `{rows}`）与 `GET /health` |

## 向量检索统一接口

各向量库在 codeact 沙箱内统一暴露 `vector_search()`，签名与返回结构一致（`query_vector` 为已 embedding 的 `list[float]`，embedding 由 Agent 侧生成）：

```python
vector_search(collection_name_or_table, query_vector, top_k=10, output_fields=None)
# -> [{ "id": ..., "score": ..., ...元数据字段 }]
```

**score 语义差异**（需注意）：

- `Milvus` / `Qdrant` / `Weaviate`：**相似度**，越大越近。
- `Chroma` / `pgvector`：**距离**，越小越近（pgvector 用 `<=>` 余弦距离 / `<->` 欧氏距离 / `<#>` 内积，通过 `metric` 参数选择）。

## Oracle / DB2 客户端依赖

Python 驱动已随 `requirements.txt` 安装，但实际连库仍需外部系统客户端：

| 数据库 | 驱动 | 外部依赖 |
|---|---|---|
| Oracle | `oracledb`（python-oracledb） | **thin 模式无需客户端**（默认）；thick 模式才需 Oracle Instant Client（`libclntsh`） |
| DB2 | `ibm_db` | **必须** IBM DB2 clidriver（`libdb2`），安装后设 `IBM_DB_HOME` 指向 clidriver 目录 |

> 代码里 Oracle 使用 `oracle+oracledb://` 方言（thin 模式），绝大多数场景开箱即用；DB2 需目标环境预置 clidriver。

## 本地起库验证（Docker，可选）

```bash
# MySQL / PostgreSQL（含演示数据，见 scripts/setup_demo_databases.sh）
bash scripts/setup_demo_databases.sh

# Qdrant
docker run -d --name qdrant -p 6333:6333 qdrant/qdrant

# Weaviate（http 8080 + grpc 50051）
docker run -d --name weaviate -p 8080:8080 -p 50051:50051 \
  -e AUTHENTICATION_ANONYMOUS_ACCESS_ENABLED=true semitechnologies/weaviate

# Chroma
docker run -d --name chroma -p 8000:8000 chromadb/chroma

# Milvus（standalone）
# curl -sfL https://raw.githubusercontent.com/milvus-io/milvus/master/scripts/standalone_embed.sh | bash
```

## 安全说明

- 数据源密码使用 **AES-256-GCM** 加密存储（`lib/security/encrypt.ts`），密钥由 `ENCRYPTION_KEY`（回退 `JWT_SECRET`）派生。
- 数据源配置仅 `branch_admin` 可增删改；查询执行受「数据范围 scope」约束（personal / branch / bank）。
